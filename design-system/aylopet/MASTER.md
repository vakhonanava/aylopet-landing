# Aylopet Design System (UI UX Pro Max — Adapted)

> **Source:** [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)  
> **Adapted for:** Premium pet nutrition · Organic Biophilic + Nature Distilled  
> **Override:** Auto-generated orange/blue palette rejected — use forest/terracotta below.

---

## Pattern: Trust + Storytelling Landing

1. **Hero** — CTA above fold, emotional headline, hero image  
2. **Trust bar** — credentials, process badges, social proof metrics  
3. **Features** — sticky scrollytelling (food → profile → DNA)  
4. **Platform modules** — block cards with imagery  
5. **Philosophy** — brand story + production visual  
6. **Social proof** — testimonials + stats  
7. **Footer CTA** — conversion close  

---

## Style: Organic Biophilic + Nature Distilled

| Token | Value | Usage |
|-------|-------|-------|
| Forest deep | `#0d2e27` | Headlines, dark accents |
| Brand primary | `#3a5a40` | CTAs, links |
| Brand accent | `#6b8f71` | Highlights, badges |
| Terracotta | `#c67b5c` | Eyebrows, warm accents |
| Bone | `#fefdf9` | Alt sections |
| Sand | `#d4c4a8` | Borders, subtle fills |
| Background | `#fbf9f6` | Page base |

**Avoid:** AI purple/pink gradients, neon, harsh 3D clay, generic SaaS blue.

---

## Typography

- **Display:** Lora — organic, calm, wellness  
- **Body:** Nunito Sans — friendly, pet-app approachable  

---

## UX Checklist (from UI UX Pro Max)

- [x] Lucide SVG icons only (no emoji icons)
- [x] `cursor-pointer` on all clickable elements
- [x] Hover transitions 150–300ms, ease-out
- [x] Visible `focus-visible` rings
- [x] `prefers-reduced-motion` respected
- [x] Touch targets ≥ 44px on mobile CTAs
- [x] Text contrast ≥ 4.5:1 in light mode
- [x] Responsive: 375 / 768 / 1024 / 1440px

---

## Effects

- Organic border-radius: 16–28px (varied)
- Soft natural shadows (`--shadow-organic`)
- Subtle grain texture on hero/CTA sections
- Parallax/tilt on hero imagery only — not decorative loops
